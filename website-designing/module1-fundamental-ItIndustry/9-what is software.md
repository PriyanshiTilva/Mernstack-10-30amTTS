What is software? List types of software in computer science. in brief

Software is a collection of programs, instructions, and data that tells a computer what to do.
It is the opposite of hardware (physical parts like keyboard, monitor, CPU).

Example:

Microsoft Word → used for typing documents
Google Chrome → used for browsing websites
Windows 11 → runs the computer system

Types of Software 
1. System Software

System software controls and manages the computer hardware and provides a platform for other software.

Examples:
Operating Systems
Windows 11
Ubuntu
macOS
Device Drivers
Utility Programs

2. Application Software

Application software helps users perform specific tasks.

Examples:
Microsoft Excel → calculations
Adobe Photoshop → photo editing
VLC Media Player → watching videos.

3. Utility Software

Utility software maintains and protects the computer system.

Examples:
Antivirus software
Disk cleanup tools
Backup software

4. Programming Software

Programming software is used to create and test programs.

Examples:
Visual Studio Code
Eclipse IDE
Compilers and debuggers.

5. Firmware

Firmware is software stored permanently inside hardware devices.

Examples:
BIOS in computers
Software inside smart TVs, routers, printers.
