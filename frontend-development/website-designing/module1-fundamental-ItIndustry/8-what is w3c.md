what is W3C and what is role of W3C in web apps?
The W3C stands for World Wide Web Consortium.
It is an international organization that creates standards and guidelines for the World Wide Web (WWW).

World Wide Web Consortium
It was founded by Tim Berners-Lee, who also invented the World Wide Web.


Main Role of W3C in Web Applications?
The W3C develops web standards so that websites and web applications work properly on all browsers and devices.

Roles of W3C:

1.Creates Web Standards
Defines standards for:
HTML
CSS
XML
Web Accessibility
Web APIs

2.Makes Websites Compatible
Ensures web apps run similarly on browsers like:
Google Chrome
Mozilla Firefox
Safari
Microsoft Edge

3.Improves Accessibility
Creates guidelines so disabled users can use websites easily.

4.Maintains Web Quality
Encourages proper coding practices and validation.

5.Supports Future Web Technologies
Develops modern technologies for secure and advanced web applications.
