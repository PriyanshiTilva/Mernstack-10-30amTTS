What is URL and list types of URL in brief ?

A URL (Uniform Resource Locator) is the address of a resource on the internet.
It tells the browser where a webpage or file is located and how to access it.


1. Absolute URL

A complete web address containing:

protocol
domain name
path

Example:
https://www.example.com/images/photo.jpg

. Relative URL

A partial address that shows the path relative to the current webpage.

Example:
/images/photo.jpg

Used mainly inside websites for internal links.
